Evenly spaced unit Student-t quantiles are assigned in ledger order for the original scenario. This deterministic placement assigns differing magnitudes across record groups and is not an identified missing-outcome distribution. The 742-case scenario recomputes the grid for all 86 synthetic outcomes, replacing the 34 original-case assignments as well as adding 52 cases; its difference from the 690-case scenario therefore does not isolate the 52 additions. The alternative reassigns the same quantiles with `numpy.random.default_rng(20261031).permutation(n)` and uses the same placement at c=1 and c=5. Both use unit likelihood weights. It is one specified alternative rather than an exhaustive permutation analysis.
