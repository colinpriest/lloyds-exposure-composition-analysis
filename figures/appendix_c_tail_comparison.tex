{\footnotesize The three estimates are mutually consistent: each point lies inside the other methods' intervals, and both EVT intervals contain the empirical point. The fitted tail shape is credibly heavy ($\hat\xi\approx0.14$ for V1, $0.14$ for V2; 95\% credible interval excludes zero), which is why the upper limits are wide. Each row is a different inferential object. The empirical row is a credible interval under the donor-composition posterior (bayesian bootstrap by syndicate x posterior draws, Dirichlet(1, ..., 1) over syndicates (Rubin's, unmodified)), with one posterior draw per replicate. The frequentist-POT row is conditional frequentist: donor resampling only, theta fixed at its posterior mean. The Bayesian-POT row is the GPD posterior.}
