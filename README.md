# IME Lloyd's Exposure Composition Analysis

Analyses the exposure composition and prior-year reserve development of Lloyd's syndicates, using data extracted from syndicate annual reports (PDFs → JSON).

## Overview

The project has three components:

- **`run_analysis.py`** — Python script that reads syndicate JSON extractions from `pdf_extraction/`, classifies data quality, computes line-of-business (LoB) weights, severity distributions, runs statistical analyses, and emits `exposure_results.json`.
- **`pdf_extraction/exposure_analysis.html`** — Static HTML dashboard that loads `exposure_results.json` and renders tables, charts, and drill-through detail. It performs no computation of its own.
- **`distortion_tool.html`** — Self-contained portfolio basis transfer tool (generated by the pipeline). The user enters a target LoB mix and reserve size; the tool applies the Section 4 composition transfer and reserve-size scaling to the donor pool and displays raw vs target-basis distributions, summary statistics, a Shapley waterfall decomposition, and per-syndicate-year worked examples. All data and dependencies are embedded — open in any browser, no server or additional files required.

## Lines of Business

The analysis covers 13 LoB categories: Property, Casualty, Marine, Energy, Motor, Aviation, Reinsurance (Property/Casualty/Specialty), Professional Lines, Accident & Health, Cyber, and Aggregate.

## Statistical Analyses

- **N0** — Descriptive statistics and data-quality classification
- **N1** — LoB weight distributions and concentration (HHI)
- **N2** — Severity distributions and tail analysis
- **N3** — Panel regression of prior-year development on LoB weights (RE-GLS with James-Stein shrinkage)
- **N4** — Bootstrap and leave-one-out robustness checks
- **N5** — Exposure composition and dispersion models (power-law fits for size and HHI effects)
- **N6** — Combined dispersion model calibration

## Setup

Requires Python 3.9+.

```bash
pip install -r requirements.txt
```

## Usage

```bash
python run_analysis.py
```

This reads all `pdf_extraction/syndicate_*_*.json` files, runs the full analysis pipeline, and writes:

- `exposure_results.json` — structured results for the dashboard
- `paper_pack/` — figures (PNG) and tables (LaTeX) for the research paper
- `vignettes/` — worked-example bundles (tables, figures, metadata) for two hypothetical syndicate vignettes
- `distortion_tool.html` — self-contained portfolio basis transfer tool (single-file artifact for submission)

### Dashboard

Open `pdf_extraction/exposure_analysis.html` in a browser and load `exposure_results.json` to explore the full analysis results interactively.

### Portfolio basis transfer tool

Open `distortion_tool.html` directly in a browser. All data (490 donors) and Chart.js are embedded — no server, no additional files, no internet connection required.

The tool applies the Section 4 composition transfer and reserve-size scaling to transfer historical market reserve movements onto a user-specified target portfolio basis. It is an upstream distributional adjustment, not a tail model or capital-setting method. The tool shows:

- KDE density plots of raw market vs target-basis signed PYD ratio distributions
- Empirical survivor function on the adverse tail (log-scale)
- Distribution statistics table (mean, std, Q75, VaR99, VaR99.5) with raw-to-adjusted deltas
- Shapley waterfall decomposition of VaR99.5 into composition and reserve-size components
- Click-through to any syndicate-year for a full worked example (LoB-level composition table, V_size calculation, percentage changes)
- Data & Settings panel showing run provenance, donor eligibility, and model coefficients
- About page explaining how to interpret each output
